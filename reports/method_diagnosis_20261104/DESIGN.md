# Post-hoc diagnosis, not tuning or confirmatory testing

Decision: prioritize task/preference validity, actor/sampler alignment or critic ranking before further tuning. Original v2/v3 outputs and trained states are immutable. No default or parameter selection follows from these checks. Model seed0 probes are descriptive, not replications; all three model seeds are used only for existing-trajectory summaries and kernel diagnostics.

1. Re-score existing final vector returns at each requested preference. Compare corresponding input preference against a fixed .125 input and all four observed input preferences within the same model/mode. Fixed .125 is a post-hoc diagnostic motivated by the raw vector returns, not a new deployable baseline or a held-out claim. Preserve paired episode differences and every weight/model.
2. Recompute shared-prefix variance comparisons at fixed leaves as well as matched actor rows. Distinguish estimation variance, induced finite-pool policy bias and episode utility. Report ESS by preference.
3. Inspect actual Gaussian prior, unit target scales and final nonzero noise. On both fixed replay states and preferences0/.5/1, use256 actual diffusion paths on each model seed. Compare final conditional means with actual noisy terminal actions, one-step expected rewards and critic utilities. This sampler intervention is a local diagnostic only: it does not define a new evaluated policy or retune noise.
4. Seed0 critic ranking: use the SAME two replay observations from diffusion's frozen replay for both methods. At each preference0/.5/1 form a common pool of8 native-prior +8 sphere +8 diffusion candidates, deduplicated. Evaluate each action then follow the appropriate BASE policy with32 independent continuation repetitions, CRN across candidate first actions. Metrics: learned-Q/ranking, paired Q-selected minus pool-average MC value, one-step selector, and two-fold cross-fitted MC-selected values (select on16 repetitions, evaluate on the other16, swap and average). Pool membership is explicitly selected, not an unbiased action population sample. Critic values target each method's own continuation, so cross-method raw-Q errors do not isolate actor quality. Two fixed states do not establish population calibration.
5. Preserve source/checkpoint/model/optimizer/global+owned RNG identities and write raw candidate/repetition arrays. Use one local CPU thread; no training or server launch. Report existing evidence separately from newly measured probes, with no significance claim.
