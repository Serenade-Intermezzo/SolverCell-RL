# SOLO：把 solver 的 cost 向量当作 diffusion 的后验充分统计量

日期：2026-11-05。研究设计，加一组 oracle 机制检验。**没有训练任何 RL 模型，没有在线 RL 结果，没有修改现有训练代码。** SOLO（Solver-consistent Localization）是工作名。

证据与脚本：[reports/localization_gate0_20261105/](../reports/localization_gate0_20261105/)。

## 0. 结论

1. **“reverse 过程可引导偏好、flow matching 做不到”不成立，不能作为论文论据。** Guided Flows、Flow Matching Guide and Code、Energy-Weighted FM、PC-Flow、PreferenceFlow 都做了 FM 引导。LSFlow 的加权 FM 本身就是一种 value tilt。仓库实测也不支持：默认阈值下 SMC 与终点加权完全相同，强制重采样（ESS=1）也没有确立收益。
2. **“diffusion 更鲁棒”目前只有一个站得住的版本**：SDE 采样的路径 KL 可由 L² 去噪误差直接控制，ODE 还需要额外的正则条件（这条出自我的记忆中的 stochastic interpolants 等文献，引用前需核对原文）。其余“鲁棒性”说法都没有证据。
3. **真正可用的结构不是“diffusion”这个品牌，而是 Gaussian 观测通道 + 随机后验采样。** 在这个结构下，posterior 是可行集上的指数族，其自然参数恰好就是 solver 的 cost 向量。LSFlow 的球面确定性 ODE 放弃了这个结构；Gaussian-path FM 加 SDE 采样可以完全恢复它。**论文必须正面承认这一点。**
4. **最值得做的算法**：把动作（而不是 cost）作为扩散的数据；把 policy improvement 写成 cost 空间里的加法；只用粒子修正线性化之后的残差。
5. **它的核心恒等式已被别人发表**（McDonald & Bartlett, 2026-10，hypercube 上 linear tilt 等于平移 denoiser 输入）。所以创新点只能落在 RL 与硬约束上，见第 6 节。
6. **最大的风险**：Intervention 上 Q 接近线性（校正后 R²≈0.9），一个不用 diffusion 的对数线性策略可能就够了。所以 Intervention 不能作为主战场。

## 2. RL-D² 的不足

**你的判断方向对，但表述要收敛。** 它不是“与组合 RL 无关”，它的动作空间确实是指数大（macro-action、联合动作、DNA），审稿人不会接受“无关”的说法。准确的说法是：**它解决的是无约束的乘积空间 A^K，不是带硬约束的组合可行集。** 全文没有出现 feasibility，脚注写明 “we focus on power sets”。LSFlow 也是这样区分它的。

## 3. Diffusion 相对 flow matching 的真实差别

| 候选优势 | 判断 | 说明 |
|---|---|---|
| 反向引导 / 偏好控制 | **不独占** | FM 同样支持；Gaussian path 下 score 与 velocity 可互换 |
| 多峰表达 | **不独占** | FM 同样多峰 |
| 鲁棒性（泛指） | **无证据** | 只有下一行的具体版本 |
| L² 去噪误差直接控制路径 KL | **属于 SDE 采样** | Girsanov 给出；对 solver 这类不连续的下游尤其相关。ODE 需要额外条件。第 5 节有初步数值支持 |
| 从中间状态重新采样后缀 | **属于随机采样** | PF-ODE 给出正确边缘，但不给出 p(a\|y) 的条件分布 |
| 后验是可行集上的指数族 | **属于 Gaussian 通道** | Gaussian-path FM 也有；**LSFlow 的球面测地路径没有** |
| 从 y=0 精确起步，无先验失配 | **属于 stochastic localization 形式** | 仓库曾诊断 VP 终点与 N(0,I) 失配，这个形式不存在该问题 |

**写论文时的口径**：不说“FM 做不到”，而说“LSFlow 选择的球面 + 确定性设计放弃了这些结构；我们的框架把 Gaussian-path FM 作为特例包含进来，并用消融实验量化随机性的贡献”。

## 4. 算法

### 4.1 一个对象

可行动作 a∈A(s)⊂{0,1}^m，嵌入 e(a)=2a−1，范数恒定。观测通道（stochastic localization 形式）：

```
y_t = t·e(a) + W_t,   t∈[0,T]
```

由此得到**精确的**后验，对任意 π 成立：

```
μ_t(a | y, s) ∝ π(a|s) · exp⟨y, e(a)⟩        （支持集始终在 A(s) 内）
dy = D(s, y, t) dt + dW,  y_0 = 0            D = E_μ[e(a)]
```

**所有操作都是 cost 空间里的加法：**

| 操作 | 在 y 上做什么 |
|---|---|
| 生成 | 按上面的 SDE 累积 y |
| 解码（solver） | a = argmax_{A(s)} ⟨y, e(a)⟩，即 LSFlow 的 a⋆(s, −y) |
| 策略改进 | 在 y+q/λ 处查询后验（y 本身不被永久改变） |
| 偏好 | q = Σ w_i q_i |
| 硬约束 | 始终在支持集里，不需要进入 y |

### 4.2 四个性质

**P1（solver 是零温去噪器）。** 当 T→∞，μ_T 的 MAP 就是线性 solver。LSFlow 的 cost 向量因此有了明确含义：它是动作的带噪观测；decision cell 是 MAP 判决域；被 Lemma 3.1 消去的范数是后验的逆温度。解码错误概率有显式上界：

```
P(argmax ≠ a) ≤ Σ_{a'≠a} Φ(−√(T·Ham(a,a')))
```

因此 T=O(log|A|) 足够（界较松）。

**P2（线性 tilt 的精确平移）。** 若 π⁺ ∝ π·exp(⟨q,e⟩/λ)，则对所有 t 有 `D⁺(y,t) = D(y+q/λ, t)`。不需要 Jacobian，不需要训练带噪 critic，任何强度都精确。枚举核验的最大误差为 2.8e-14。多次 PMD 迭代退化为 dual averaging：cost 向量就是 PMD 的对偶变量。

**P3（残差分解）。** 写 Q = ⟨g,a⟩ + R，用 P2 作提议，粒子权重只需 exp(R/λ)。π 被约掉，**不需要动作密度**（RL-D² 正是被这个密度卡住才用 single-step ratio）。K→∞ 时对精确 denoiser 一致。

**P4（重线性化链）。** 对强交互的 Q，在链上按当前后验均值重算 g：`g_t = ∇_a Q(s, D(y_t, t))`。随机噪声打破对称后，局部梯度才有信息。这是多步随机链的具体作用，第 5 节有消融。

### 4.3 与已有方法的关系

| 方法 | 在此框架下对应 |
|---|---|
| SRL | π 为对数线性、单一 cost 的特例（perturb-and-MAP 近似） |
| LSFlow | 跳过链、直接学 cost 分布并解码；vMF 平滑相当于热半群的单一时间切片 |
| Perturbed optimizer 梯度 | 给定噪声水平下平滑值函数的 Stein 梯度 |
| RL-D² FKL | 同样的 PMD 投影，但无约束、无平移、权重承担全部改进 |
| Gaussian-path FM + SDE | 同一过程的另一种参数化 |

### 4.4 训练循环

```
执行： y←0; for k: g←∇_aQ̄(s,D_θ(s,y+sh,t_k)); sh←g/(2λ);   # ⟨g,a⟩=⟨g/2,e⟩+常数，故 q=g/2
                   y←y+h·D_θ(s,y+sh,t_k)+√h·ε
      a←Solver(s, y+sh)                       # 每步环境只调用一次 solver
Critic：y=r+γ·Q̄(s',a')，Q 的输入是真实动作     # 不动点是 Q^π，没有 κ 偏差
Actor： 取状态 s，用 P2/P4 提议 K 个动作，按 P3 残差权重重采样得 a⁺
       min ‖D_θ(s, t·e(a⁺)+√t·ε, t) − e(a⁺)‖²  # FKL 投影，权重不再承担主要改进
```

**可选的结构化 denoiser**：`D_θ = M_{A(s)}(2y + f_θ(s,y,t))`，其中 M_A 是 A(s) 上指数族的均值映射。网络只学与“A(s) 上均匀分布”的差别，A(s) 变化不需要重新学。top-k 可用 DP 精确且可微地计算，这也是实验脚本的 oracle；一般 MIP 需要近似。

**Solver 成本（待解决）。** LSFlow 指出动作空间 critic 的 solver 调用极贵。TD 目标里的 a' 有两种选择：解码便宜时用真实解码；MIP 场景用 D_θ(s,y_T,T) 的松弛均值，T 足够大时接近顶点。第二种的偏差还没有测过。

### 4.5 对应 LSFlow 自己列出的未来工作

| LSFlow 的局限 | SOLO 的回应 | 状态 |
|---|---|---|
| 平滑的偏差-方差权衡 | critic 在真实动作上，不动点无 κ 偏差 | 设计；真实动作 critic 的风险见第 8 节 |
| 求解器推理开销 | 仍是每决策一次 solver，生成步数更少 | 待测 |
| 反传采样器不稳定 | 只用 ∇_aQ，不穿过采样器 | oracle 下成立 |
| 多目标 solver 接口 | q 可加 | 线性部分精确；实际效果未测 |

### 4.6 候选理论结果

- **T1 对偶**：P1 与第 4.3 节的统一视角。
- **T2 分离**：任意基于 K 个样本的零阶重加权增益 ≤ σ√(2 ln K)；当 Q 可加时，一次梯度的平移可达 βσ。证明直接。
- **T3 近似 PMD**：`KL(π⁺‖π_θ) ≤ ½∫E‖D−D_θ‖²dt + 解码误差`，再经性能差分引理得到回报保证。这是 LSFlow 的加权 FM 损失给不出的（ODE 情形缺少这种直接控制）。
- **T4 无偏 critic**：不动点就是 Q^π。

这些都还没有完整写出证明。

### 5.4 从这些数字能得出什么

**支持：**
- 在 Q 接近可加时，平移类方法相对粒子重加权有大幅优势，且残差修正能拉回过冲。
- 重线性化链能处理固定梯度完全失败的 AND/XOR。这是多步链的具体作用。
- 去掉生成链（mean-field）后，XOR 和中等温度的 AND 明显失败；AND β=10 时多样性塌缩到 2.2。

**不支持或存疑：**
- **Q 接近可加时不需要链。** 平移+残差已经接近采样下限。而且这组实验的 base 是均匀分布，一个对数线性策略就能做到。
- **SDE 对 ODE 的优势是中等的且有条件。** Sigmoid 上差距明显，XOR 上较小，AND 上互有胜负。ODE 对照只实现了一种，且 ODE64 常比 ODE16 差，部分差距可能来自状态相关引导与 PF-ODE 不相容，或者我的实现，不能当作定论。
- **SDE 没有全面胜出。** XOR β=10 的 TV 仍有 .36–.38（下限 .069），这里残差粒子最好。AND β=5 时 SDE64 反而比 SDE16 差，原因未查明。
- 16 步均匀网格的 SDE 在 sigmoid 上过冲 3–39%（β 越小越明显）。二次网格、64 步时明显减小，因此至少部分是离散化偏差，需要更好的网格。

**完全没有测的（最大的未知）：**
- **Denoiser 是 oracle。** 学习得到的 denoiser 在平移后的输入上可能不准，Internal Guidance 的作者也明确指出这一点。仓库的固定分布拟合门槛（TV≤.15）此前没有一个方法通过。
- **Critic 是精确的或只带平滑误差。** 真实神经网络 critic 在松弛输入上的梯度可能差得多。
- 没有在线 RL。没有状态分布、没有探索、没有 Bellman 耦合。

### 5.5 真实 Intervention 的线性度

instance 0，24 个状态的即时奖励 R² 均值 .817（最小 .587）。9 个状态的长期 Q（myopic 延续，均匀动作，每动作 8 次 rollout）原始 R² .41–.73，split-half 可靠性 .38–.75；校正自由度和噪声后 .80–1.0，均值 .91。这只是一个实例、一个延续策略、均匀动作分布，不代表最优动作附近的局部曲率。

**含义有两面**：P2/P3 在这个任务上大概率有效；但也说明**对数线性策略是必须跑的强对照**，它可能在 Intervention 上就够了。主实验必须放在交互更强的任务上。

文献检索不是穷尽的，只做了若干轮定向搜索，投稿前还要再查。

| 已有工作 | 已占据 | SOLO 必须额外提供 |

| [pCN steering](https://neurips.cc/virtual/2026/poster/153197) | MH 校正的 reward 引导 | 不做 RL 与离散动作；所以我没有把 MH 放进核心 |

**可主张的贡献（按稳固程度）：**
1. 在线组合 RL 中，把 PMD 拆成“cost 空间的线性平移 + 残差粒子”，并给出相对零阶重加权的分离结果和实证。
2. Solver 作为零温 MAP 去噪器的对偶，把 LSFlow、SRL、perturbed optimizer 放进同一框架。这一条是否已有人写过需要进一步确认，因为数学上并不难。
3. 硬约束下无 κ 偏差的 critic。

**时效风险**：Internal Guidance 刚出现，LSFlow 作者把直接价值最大化列为未来工作，这个方向存在被抢先的可能。

## 8. 风险

1. **学习的 denoiser 拟合不好**（最可能的失败点）。仓库已有 TV .25–.29 的先例。结构化 denoiser 是针对性假设，未经验证。
2. **动作空间 critic 不健康。** 历史 matched-harness 中动作 critic 回报 147–181，native 316。当时同时改了很多东西，原因未完全分离。G2 必须单独排查，且优先沿用 native 的 Q 归一化和更新节奏。
3. **松弛输入上的 critic 梯度不可靠**，平移可能把策略推向错误方向。残差权重能部分修正，但修正不了大方向错误。
4. **Intervention 实际只有 268 类动作**，无法展示规模优势。
5. **Q 高度线性的任务上**，整个多步生成可能没有必要。

## 9. 最大熵目标、风格偏好与任务选择（2026-11-05 增补）

本节回应三项决定：目标改为最大熵；“偏好”指驾驶风格式的快速/平稳/舒适；主实验放在组合路径/调度任务。证据见 [reports/style_routing_probe_20261105/](../reports/style_routing_probe_20261105/README.md)，全部是已知 myopic 目标、精确 denoiser，**不是 RL 结果**。

### 9.1 目标

```
max E Σ γ^t [ w·r(s,a) − α·KL(π(·|s) ‖ ρ(·|s)) ]
π*_w ∝ ρ·exp(Q(s,a,w)/α)
V_w(s) = α·log E_ρ[exp(Q/α)]
log E_ρ[exp(Q/α)] = ∫₀¹⟨q/α, D(τq/α, 0)⟩dτ + log E_{π_lin}[exp(R/α)]
```

ρ 固定；均匀时即标准最大熵。第一项只需 t=0 的去噪器查询，所以 soft value 不需要 log π。枚举核对（m=14，K=12，脚本 `localization_gate0_20261105/softv.py`）：β=2/5/10 时偏差 −.04/−.22/−.62，普通粒子为 −.27/−2.65/−7.41。

w 决定风格，α 决定随机程度，二者分开。Critic 需要 `Q(s,a,w)` 或 successor features 加一个熵头，不能把各目标的 Q 简单相加。

### 9.2 路径任务原型：Style-Routing

动作是 40 站地铁图上时间展开的 T=20 步闭合路径，状态为（站，线路），只允许在 depot 等待。这沿用发布 MIP 的时间展开思路，但解决了发布解码器不保证可行的问题。

| 项目 | 结果 |
|---|---|
| 规模 | 8500 个 bit，约 1e14 条路线（Intervention 只有 268 类） |
| DP 与枚举对比（T=6） | log Z 误差 1.8e-14，边际误差 1e-15，solver 一致 |
| 单次耗时（Python，CPU） | solver .40 ms，后验均值 .75 ms；不需要 MIP |
| 风格指标 | 用时和换乘来自真实数据；拥挤度用线路数作代理，不是实测 |

**风格冲突（启发式参考解，并非最优，12 个状态）**：

| 权重 | 换乘：服务/换乘 | 用时：服务/分钟 | 拥挤：服务/拥挤 |
|---:|---:|---:|---:|
| 0 | 20.0/12.2 | 19.2/49.7 | 20.2/59.2 |
| .4 | 18.3/5.9 | 18.9/41.6 | 18.9/47.7 |
| .8 | 17.7/3.6 | 9.8/16.8 | 8.4/15.1 |
| 1.6 | 17.1/1.9 | 1.4/0.4 | 1.0/0.0 |

换乘有平滑的权衡。用时和拥挤在 .4–1.6 之间陡降，最后退化成几乎不出发，需要按极端参考策略的跨度校准尺度，否则会重复 Intervention 上的问题。

**等预算比较（6 个实例，增益单位为标准差）**：

| 目标 | β | 参考目标 | SNIS12 | 对数线性 | 平移+残差12 | SDE16 |
|---|---:|---:|---:|---:|---:|---:|
| 覆盖 + 成本 | 2 | 2.43 | 1.35 | 2.30 | **2.41** | 1.62 |
| 覆盖 + 成本 | 5 | 6.03 | 1.55 | 5.72 | **6.00** | 4.33 |
| 覆盖 + 成本 | 10 | 7.53 | 1.68 | 6.97 | **7.21** | 6.75 |
| 街区奖励 | 2 | 5.33 | 1.71 | 1.26 | **2.67** | 1.77 |
| 街区奖励 | 5 | 7.83* | 1.69 | 2.89 | **4.55** | 2.41 |
| 街区奖励 | 10 | 6.38 | 1.91 | 2.01 | **4.56** | 2.12 |

*该格参考解 ESS 仅 3.9，不可靠。“街区奖励”要求走完一组 4 站才有奖励，并有 4 个相互竞争的街区。T=32、32 步的 SDE 没有改善（1.88/2.38/1.87）。

Heldout ridge 对服务奖励的 R² 为 .37–.71，样本（1800）远少于维度（8500），只能算下界。

### 9.3 这改变了什么判断

1. **平移+残差在所有路径实验里最好，而且不需要生成链。** 目标算法的核心很可能是这个分解，不是 diffusion。
2. **这里的重线性化 SDE 链没有优势。** 这与第 5 节 k-子集上的 AND 结果相反，原因未查明，可能是 8500 维下早期梯度过小，也可能是 T 和离散化。它只在模式覆盖上好一些：街区奖励下 SDE16 完成过的街区数为 2.83/2.5/2.0，对数线性为 1.0/.83/.67，但增益并不高。第 4.2 节的 P4 因此降级为待查的可选项。
3. **路径任务上均匀 ρ 能精确采样，因此根本不需要学习的去噪器。** 这是“不用 diffusion”的强对照，必须作为基线。
4. **Diffusion 的存在理由只剩两处，都未验证：**
   - **可行集难以精确处理时**（scheduling、assignment）：指数族均值和均匀采样没有多项式算法，学习的去噪器加 solver 解码可能是可用的替代。
   - **跨轮固化残差时**：街区奖励下平移+残差（4.55）与参考目标（约 6–8）的差距，要靠把改进后的样本蒸馏进网络，多轮 PMD 才可能追上。

### 9.4 任务方案

| 任务 | 角色 | 现状 |
|---|---|---|
| Style-Routing | **校准任务**：有精确 log Z、均值和采样，能直接测学习的去噪器误差 | 原型已有，未接入 MDP 动态 |
| Style-Scheduling | **主张任务**：没有精确 DP，最能检验 diffusion 是否必要 | 未做。需返回 `(a,x)` 并以开源 MILP 替换 Gurobi；迟到是 x 的线性特征，工人均衡是非线性的 |
